# Knowledge Base RAG (`data/knowledge`)

Tempat menyimpan dokumen pengetahuan untuk pipeline RAG (daftar menu, resep standar, FAQ, SOP operasional, dan aturan pembayaran DP/pelunasan) yang telah divalidasi PIC UMKM.

**Metadata Wajib:** Setiap dokumen menyertakan informasi sumber, tanggal pembaruan, versi, dan status validasi.
