# Dataset Sintetis (`data/synthetic`)

Tempat menyimpan dataset sintetis untuk eksperimen klasifikasi relevansi, forecasting, atau analisis sentimen.

**Persyaratan:** Setiap dataset sintetis wajib menyertakan kolom/penanda `is_synthetic`, dokumentasi metode pembangkitan, dan pemisahan tegas dari data evaluasi nyata agar tidak terjadi kebocoran data.
