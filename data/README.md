# Ruang Kerja Data (`data/`)

Direktori penyimpanan dataset dan dokumen pengetahuan Smart Catering sesuai pembagian akses dan tata kelola data:

- `raw/` — Data primer UMKM yang telah dianonimkan (diabaikan oleh Git kecuali `README.md`).
- `synthetic/` — Dataset sintetis berlabel dengan penanda `is_synthetic`.
- `knowledge/` — Dokumen pengetahuan RAG tervalidasi PIC beserta metadata sumber, tanggal, versi, dan status validasi.
- `dictionary/` — Kamus data untuk tabel transaksi, fitur machine learning, dan dataset analitik.
