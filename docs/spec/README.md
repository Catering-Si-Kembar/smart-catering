# Spesifikasi Teknis Tim (`docs/spec`)

Direktori spesifikasi teknis bersama untuk koordinasi implementasi lintas tim:

- Mockup UI dan alur layar web.
- Skema database dan Entity-Relationship Diagram (ERD).
- Kontrak API `/api/v1` dan pemetaan payload wire contract.
- Daftar pembagian issue dan backlog modul fitur: lihat [Indeks Spesifikasi Issue](issues/README.md).

## Struktur Direktori

- `issues/` — Paket spesifikasi teknis 27 issue kerja:
  - `01-fullstack.md` (FS-01 – FS-09)
  - `02-data-science.md` (DS-01 – DS-06)
  - `03-ai-engineering.md` (AI-01 – AI-07)
  - `04-devops-infra.md` (OPS-01 – OPS-05)
