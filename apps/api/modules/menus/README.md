# Modul `menus`

Batas modul untuk katalog menu, daftar bahan baku, resep standar terkonfirmasi UMKM, dan kalkulasi otomatis kebutuhan bahan baku berdasarkan jumlah porsi (tanpa manajemen stok real-time).

**Boundary:** Skeleton struktural. Logika resep, satuan bahan, dan kontrak validasi diimplementasikan pada fase pengembangan modul bisnis.
