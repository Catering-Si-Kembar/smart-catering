# Modul `chat`

Batas modul untuk penyimpanan riwayat percakapan di PostgreSQL, pemeriksaan hak akses peran di backend (bukan di prompt), penyediaan data baca-saja untuk tools, dan delegasi inferensi ke `apps/ai-service`.

**Boundary:** Skeleton struktural. Skema riwayat chat, kontrol akses peran, dan klien RAG diimplementasikan pada fase pengembangan modul bisnis.
