# Modul `analytics`

Batas modul untuk agregasi KPI dasbor analitik, validasi unggahan file data, serta orkestrasi ke layanan forecasting, analisis sentimen, dan AI Business Insight di `apps/ai-service`.

**Boundary:** Skeleton struktural. Agregasi metrik dan endpoint analitik diimplementasikan pada fase pengembangan modul bisnis.
