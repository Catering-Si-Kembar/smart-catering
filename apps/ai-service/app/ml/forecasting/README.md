# Sub-modul `forecasting` (`apps/ai-service/app/ml/forecasting`)

Batas modul estimasi permintaan menu dan kebutuhan bahan baku menggunakan baseline Moving Average dan Random Forest dengan fitur lag/rolling serta evaluasi kronologis MAE, RMSE, dan WAPE.

**Boundary:** Menyajikan hasil estimasi beserta batasan cakupan data historis yang dipakai, tanpa jaminan akurasi operasional penuh.
