# Sub-modul `sentiment` (`apps/ai-service/app/ml/sentiment`)

Batas modul klasifikasi sentimen feedback pelanggan (kelas positif dan negatif), penanganan ketidakseimbangan kelas, dan ringkasan sentimen untuk dasbor analitik.

**Boundary:** Dataset sintetis yang dipakai dalam eksperimen wajib ditandai `is_synthetic` dan tidak disajikan sebagai feedback pelanggan nyata.
